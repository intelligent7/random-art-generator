# Random Art Generator

This Python project uses the `turtle` module to create unique, random art patterns with colorful lines and shapes. Each run generates a different design!

## Requirements
- Python 3.6+ (comes with `turtle` built-in).

## How to Run
1. Open a terminal in the project directory.
2. Run: `python art_generator.py`
3. A window will pop up displaying the art. Close the window to end the program.

## Features
- Random colors and line lengths.
- Dynamic pattern generation.
- Fun and educational visualization.
